{# ── Paginación compartida (P1..P4) ────────────────────────────── Uso: {% from 'components/paginacion.html' import paginacion %} {{ paginacion(pagina, total, por_pagina, filtros_qs) }} - filtros_qs: query string de los filtros activos SIN 'pagina'. Lo calcula cada ruta en Python (_filtros_sin_pagina de app.py) porque en Jinja un {% set %} dentro de un {% for %} no sale del bucle. Enlaces: ?{{ filtros_qs }}&pagina=N (o ?pagina=N si no hay filtros). - Solo se pinta si total > 0: con total == 0 la página muestra su propio estado vacío (nunca "Mostrando 1–0 de 0"). - Accesible: nav aria-label, aria-current="page" en la página actual, enlaces con aria-label. Móvil (<576px): solo anterior/siguiente y "Pág. X de Y" (números y "Mostrando…" ocultos), sin scroll horizontal (flex-wrap + paginación compacta). - Los {% set %} de abajo viven a nivel de macro (fuera de bucles): el cálculo de ventana usa solo expresiones, sin mutación interna. #} {% macro paginacion(pagina, total, por_pagina, filtros_qs='') %} {% if total > 0 %} {% set ultima = ((total + por_pagina - 1) // por_pagina) %} {% set sep = filtros_qs ~ ('&' if filtros_qs else '') %}
Mostrando {{ (pagina - 1) * por_pagina + 1 }}–{{ [pagina * por_pagina, total] | min }} de {{ total }}
  • «
  • Pág. {{ pagina }} de {{ ultima }}
    • {% if ultima <= 7 %} {% for p in range(1, ultima + 1) %}
  • {{ p }}
    • {% endfor %} {% else %}
  • 1
    • {% if pagina > 4 %}
  • …
    • {% endif %} {% for p in range([pagina - 2, 2] | max, [pagina + 2, ultima - 1] | min + 1) %}
  • {{ p }}
    • {% endfor %} {% if pagina < ultima - 3 %}
  • …
    • {% endif %}
  • {{ ultima }}
    • {% endif %}

{% endif %} {% endmacro %}
